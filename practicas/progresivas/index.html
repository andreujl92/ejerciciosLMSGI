De HTML sin estilos a web adaptable

Seis prácticas encadenadas sobre un único fichero HTML, la web del Club Náutico Mal Pas. Cada una aplica una parte del diseño con los contenidos de una sección de la teoría, hasta dejarlo terminado en la última.

Cómo funciona

  • Todo el alumnado parte de la misma web base (ZIP): una página completa, válida y semántica, con las clases ya puestas y sin ningún estilo.
  • El HTML no se toca en toda la serie (solo se enlazan la hoja y la fuente en la PP 3.1). Todo sale de css/estilos.css, que crece práctica a práctica: es la mejor demostración de las ventajas de las hojas de estilo (CE 2g).
  • Algunas soluciones son provisionales a propósito (por ejemplo, tarjetas con inline-block en la PP 3.2) y se sustituyen después por Flexbox y Grid, para que se vea qué problema resuelve cada técnica.
  • Cada enunciado trae capturas del resultado esperado en escritorio y en móvil, enlaces al laboratorio CSS para probar las propiedades antes de escribirlas y una lista de comprobación.
