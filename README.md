## ⌨️ Controles del Reproductor Interactivo

- <kbd>←</kbd> / <kbd>→</kbd> : Navegar paso a paso hacia atrás o hacia adelante.
- <kbd>Espacio</kbd> : Iniciar / Pausar reproducción automática.
- <kbd>R</kbd> : Reiniciar al paso inicial.
- Clic en cualquier paso del enunciado para saltar directamente a ese momento del ejercicio.
